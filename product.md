# Buena — Product Overview

## What Buena Is

Buena acquires traditional German property management companies (Hausverwaltungen) and runs them on a unified platform. Property managers get one place for every building, contract, and process — instead of folders and Excel.

---

## Case Study Scope

A focused MVP with two surfaces:

1. **Property Creation Flow** — a guided flow to register a new property into the system
2. **Dashboard** — displays all created properties at a glance

That's it. No accounting, no tenant comms, no compliance. The goal is to show that adding a property is fast and that the result is immediately visible.

---

## Users

**Property Manager** — the primary user. They manage a portfolio of buildings. They need to register new properties quickly and see their portfolio without hunting through files.

---

## Core Flows

### 1. Create a Property

The manager fills in the essential details of a property and submits. The property is then saved to the system.

**Likely fields:**
- Property name
- Address (street, city, postal code)
- Property type (residential, commercial, mixed)
- Number of units
- Year built (optional)

The flow should feel fast and low-friction. One screen or a short stepped form — no unnecessary fields.

### 2. Property Dashboard

After creation, the property appears on the dashboard. The dashboard gives the manager a bird's-eye view of their portfolio.

**What the dashboard shows:**
- List or grid of all properties
- Key info per property: name, address, type, unit count
- Empty state when no properties exist yet (clear call to action to add the first one)

---

## What "Done" Looks Like

A property manager can:
- Open the app and see their property portfolio immediately
- Add a new property in under 2 minutes
- See the newly created property on the dashboard without a page refresh
